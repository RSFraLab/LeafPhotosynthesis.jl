Excitation, Electron Transport & Stoichiometry ​

Excitation types (BroadbandExcitation, PrescribedPSIIExcitation, PrescribedDualExcitation) pass absorbed photon fluxes from external leaf/canopy optics into photosystems II and I without embedding spectral pigment tables inside LeafModel. Potential electron supply is evaluated either from empirical non-rectangular hyperbola parameters (ElectronTransportParameters, electron_transport) or from Cytochrome series kinetics with linear and cyclic ATP/NADPH stoichiometry (CytochromeElectronParameters, CytochromeStoichiometry).

Walkthroughs: Excitation contract, Cytochrome b6f mechanics.

LeafPhotosynthesis.PrescribedPSIIExcitation Type
julia
PrescribedPSIIExcitation(photons)
PrescribedPSIIExcitation{FT}(photons)
PrescribedPSIIExcitation(; photons)

Carry externally allocated PSII excitation photons [μmol photons m⁻² leaf s⁻¹] on the same one-sided leaf-area basis and PAR spectral interval as LeafEnvironment.absorbed_par.

Pigment and antenna allocation are already included, so broadband psii_fraction is not applied again. Invalid values are stored without throwing for GPU compatibility; valid_excitation rejects non-finite or negative values and photons > absorbed_par. A binary precision other than that of the model and environment is a MethodError of the entry point.

source
LeafPhotosynthesis.PrescribedDualExcitation Type
julia
PrescribedDualExcitation(psii_photons, psi_photons)
PrescribedDualExcitation(; psii_photons, psi_photons)

Carry externally allocated PSII (psii_photons) and PSI (psi_photons) excitation fluxes [μmol photons m⁻² leaf s⁻¹] on the same leaf-area basis and PAR spectral interval as LeafEnvironment.absorbed_par.

valid_excitation requires finite nonnegative absorbed_par, psii_photons ≥ 0, psi_photons ≥ 0, psii_photons + psi_photons ≤ absorbed_par (permitting non-photosynthetic pigment absorption when strict inequality holds). A binary precision other than that of the model and environment is a MethodError.

source
LeafPhotosynthesis.valid_excitation Function
julia
valid_excitation(excitation, total_absorbed_par) -> Bool

Return true if excitation and total_absorbed_par lie in the domain shared across photosynthesis, turnover, diffusion, oxygen, and fluorescence entry points: finite nonnegative light, and prescribed photon fluxes that are finite, nonnegative and no larger than total_absorbed_par. Different binary precisions are a MethodError.

psii_excitation(electron_parameters, total_absorbed_par, excitation)

Return the PSII photon flux [μmol photons m⁻² leaf s⁻¹] delivered to PSII reaction centers prior to multiplication by photochemical yield, or typed NaN when valid_excitation fails.

source
LeafPhotosynthesis.psi_excitation Function
julia
psi_excitation(electron_parameters, total_absorbed_par, excitation)

Return the PSI photon flux [μmol photons m⁻² leaf s⁻¹] delivered to PSI reaction centers prior to multiplication by PSI photochemical yield, or typed NaN when valid_excitation fails.

PrescribedPSIIExcitation intentionally has no psi_excitation method because non-photosynthetic pigment absorption prevents inferring PSI photons as PAR - Q₂.

Potential Electron Supply ​

LeafPhotosynthesis.ElectronTransportParameters Type
julia
ElectronTransportParameters(; psii_fraction, psii_yield, limitation)
ElectronTransportParameters(psii_fraction, psii_yield, limitation)

Specify the broadband PSII photon fraction psii_fraction (∈ [0, 1]), maximum PSII electron yield per delivered photon psii_yield (∈ [0, 1]), and rate co-limitation model limitation.

Leaf absorptance belongs to optics and is not included in psii_fraction. Throws ArgumentError if psii_fraction or psii_yield is outside [0, 1].

source
LeafPhotosynthesis.electron_transport Function
julia
electron_transport(parameters, absorbed_par, jmax, excitation=BroadbandExcitation())

Compute available linear electron transport [μmol electrons m⁻² leaf s⁻¹] from absorbed PAR [μmol photons m⁻² leaf s⁻¹] and capacity jmax [μmol electrons m⁻² leaf s⁻¹].

BroadbandExcitation() delivers the fraction psii_fraction of absorbed_par to PSII; prescribed excitation conventions bypass broadband psii_fraction. Every convention returns typed NaN when valid_excitation is false; parameters, light and excitation of different binary precisions are a MethodError.

source
LeafPhotosynthesis.CytochromeElectronParameters Type
julia
CytochromeElectronParameters(; psii_fraction, psi_maximum_yield, limitation)
CytochromeElectronParameters(psii_fraction, psi_maximum_yield, limitation)

Specify broadband PSII photon partition psii_fraction (β ∈ (0, 1)), open-center PSI maximum photochemical yield psi_maximum_yield (Φ_P1,max ∈ (0, 1)), and rate co-limitation model limitation (SerialLimitation for Johnson & Berry 2021, Eq. 20).

source
LeafPhotosynthesis.cytochrome_electron_supply Function
julia
cytochrome_electron_supply(parameters, total_absorbed_par, vqmax,
    excitation=BroadbandExcitation())

Evaluate potential PSI electron supply psi_electron_supply [μmol e⁻ m⁻² leaf s⁻¹] co-limited by Cytochrome b₆f capacity vqmax, together with the steady-state open PSII reaction-center fraction psii_open_fraction (q₂, Johnson & Berry 2021, Eq. 22).

Single-photosystem illumination (iszero(Q₂) != iszero(Q₁)) lies outside the coupled Z-scheme steady-state domain and returns NaN fields.
