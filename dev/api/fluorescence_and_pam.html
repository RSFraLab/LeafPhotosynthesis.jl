Chlorophyll Fluorescence, State Transitions & PAM ​

Internal photosystem fluorescence yields and emitted photon fluxes are computed from the same photosystem excitations and realized electron flows used by carbon assimilation, either through empirical PSII rate competition with replaceable non-photochemical quenching (RateCompetitionFluorescence, ConstantQuenching, SaturationQuenching) or through coupled PSII/PSI + Cytochrome redox feedback (CytochromeFluorescence). Closed-form LHCII state transitions (qT, StateTransitionRule) and apparent Pulse-Amplitude-Modulated fluorometry with PSI detector leakage (PAMFluorescenceObserver) compose directly on top of the steady-state photosystem states.

Walkthroughs: PSII fluorescence, Cytochrome b6f stress fluorescence, Flexas (2002) water-stress SIF.

Photosystem Rate Parameters & Flux Inputs ​

LeafPhotosynthesis.PSIIRateParameters Type
julia
PSIIRateParameters(; fluorescence_rate, constitutive_heat_rate,
    maximum_photochemical_rate, exciton_transfer_rate, sustained_quenching_rate)
PSIIRateParameters(fluorescence_rate, constitutive_heat_rate,
    maximum_photochemical_rate, exciton_transfer_rate, sustained_quenching_rate)

Specify first-order PSII excitation decay and inter-unit transfer rate constants sharing a common normalization (conventionally ns⁻¹, Johnson & Berry 2021, Table 1):

  • fluorescence_rate (K_F2 > 0).

  • constitutive_heat_rate (K_D2 ≥ 0).

  • maximum_photochemical_rate (K_P2 > 0).

  • exciton_transfer_rate (K_U2 ≥ 0; 0 selects the separate-units puddle limit, > 0 selects connected-units exciton sharing).

  • sustained_quenching_rate (K_N,sus ≥ 0; dark-sustained thermal dissipation).

julia
fluorescence_inputs(photosynthesis, site::LeafEnvironment, excitation=BroadbandExcitation())
fluorescence_inputs(leaf, site::LeafEnvironment, excitation=BroadbandExcitation())

Return the inputs of fluorescence from the signed turnover of photosynthesis at the biochemical site site: a PSIIFluxInputs (PSII excitation and realized linear electron flow) for C3Photosynthesis, a CoupledPhotosystemInputs (PSII and PSI excitations, realized linear J_P680 and PSI J_P700 electron flows, open PSII fraction q₂) for CytochromePhotosynthesis.

Closed-Form LHCII State Transitions (qT) ​

LeafPhotosynthesis.StateTransitionRule Type
julia
StateTransitionRule{FT}(; minimum_psii_fraction=zero(FT), maximum_psii_fraction=one(FT))
StateTransitionRule(; minimum_psii_fraction, maximum_psii_fraction)
StateTransitionRule(minimum_psii_fraction, maximum_psii_fraction)

Configure closed-form state-transition antenna partitioning (qT; Johnson & Berry 2021, Eqs. 25a, 28, 30a, Cases 10–12) with optional LHCII mobility bounds 0 ≤ minimum_psii_fraction < maximum_psii_fraction ≤ 1.

Under Cytochrome b₆f limitation (J_P700,j ≤ J_P700,c), solves analytically for the PSII absorbed-photon fraction β = Q₂ / Q_abs that balances linear and cyclic electron transport at K_N = 0, freezing β at its light-saturation crossover value β_sat above J_P700,j ≥ J_P700,c.

source

Compute the low-light (Q_abs → 0, q₂ → 1, K_N = 0) PSII absorbed-photon fraction    that balances open-center PSII and PSI photochemistry (Johnson & Berry 2021, Eqs. 28, 30, Table 2), returning NaN on invalid inputs without throwing.
