Temperature Responses & Photorespiratory Compensation ​

Thermal kinetics evaluate scalar rate laws (ConstantResponse, Arrhenius, PeakedArrhenius) at leaf temperature T [K] without embedded reference temperatures or gas constants. Rate bundles assemble all temperature-dependent capacities and Michaelis–Menten constants for Farquhar–von Caemmerer–Berry C3 biochemistry (C3TemperatureResponse, C3Rates) and Johnson & Berry (2021) Cytochrome coupling (CytochromeCapacity, CytochromeTemperatureResponse, CytochromeRates), paired with prescribed or explicitly oxygen-scaled photorespiratory compensation points [Pa].

Walkthroughs: Bonan 11.1 curves, Oxygen response.

Scalar Thermal Response Laws ​

LeafPhotosynthesis.AbstractTemperatureResponse Type
julia
AbstractTemperatureResponse

Supertype of temperature-response laws evaluated by temperature_response: Arrhenius, PeakedArrhenius, ConstantResponse and CytochromeCapacity.

Implementation

A new law subtypes AbstractTemperatureResponse and adds a method temperature_response(law, temperature); the rate bundles accept it in every field.

source
LeafPhotosynthesis.ConstantResponse Type
julia
ConstantResponse(value)
ConstantResponse(; value)

Wrap a temperature-independent continuous scalar parameter value for uniform temperature_response dispatch alongside Arrhenius and PeakedArrhenius.

Requires a finite continuous scalar (AbstractFloat or dual number) and propagates typeof(value + zero(temperature)) so automatic differentiation preserves homogeneous rate types.

Examples

julia
julia> using LeafPhotosynthesis: temperature_response

julia> r = ConstantResponse(0.75);

julia> temperature_response(r, 303.15)
0.75
source
LeafPhotosynthesis.Arrhenius Type
julia
Arrhenius{FT}(; value_ref, activation_energy, temperature_ref, gas_constant)
Arrhenius(value_ref, activation_energy, temperature_ref, gas_constant)

Construct an Arrhenius temperature response   normalized at temperature_ref (T_ref [K]).

activation_energy (E_a) has units of J mol⁻¹ and gas_constant (R) has units of J mol⁻¹ K⁻¹; value_ref (k_ref) carries the units of the quantity being scaled. All scientific parameters are supplied explicitly. Throws ArgumentError unless value_ref and activation_energy are finite and temperature_ref and gas_constant finite and positive.

Examples

julia
julia> using LeafPhotosynthesis: temperature_response

julia> law = Arrhenius(60.0, 65330.0, 298.15, 8.314);

julia> temperature_response(law, 298.15)
60.0

LeafPhotosynthesis.PeakedArrhenius Type
julia
PeakedArrhenius(; arrhenius, deactivation_energy, entropy)
PeakedArrhenius(arrhenius, deactivation_energy, entropy)

Construct an Arrhenius temperature response with high-temperature thermal inhibition normalized at arrhenius.temperature_ref (T_ref [K]):          .

deactivation_energy (H_d) is in J mol⁻¹ and entropy (ΔS) is in J mol⁻¹ K⁻¹. Throws ArgumentError unless both are finite.

source
LeafPhotosynthesis.temperature_response Function
julia
temperature_response(response, temperature)

Evaluate response at leaf temperature [K]; the result has the units of the response's reference value. Temperature must be finite and positive: any other value gives NaN (also for ConstantResponse). A response and a temperature of different binary precisions are a MethodError.

LeafPhotosynthesis.C3TemperatureResponse Type
julia
C3TemperatureResponse(; vcmax, jmax, respiration, kc, ko, gamma_star)

Bundle the six C3 biochemical temperature responses (vcmax, jmax, respiration, kc, ko, and gamma_star).

Every field is an AbstractTemperatureResponse; gamma_star may also be an explicit AbstractCompensationPoint component.

Store evaluated C3 biochemical kinetic parameters at leaf temperature and, when selected, biochemical-site O₂.

LeafPhotosynthesis.CytochromeTemperatureResponse Type
julia
CytochromeTemperatureResponse(; vcmax, vqmax, respiration, kc, ko, gamma_star,
    linear_atp_per_electron, cyclic_atp_per_electron)

Bundle temperature and oxygen response laws for Cytochrome b₆f C3 biochemistry (Johnson & Berry 2021).

Every field is an AbstractTemperatureResponse: vqmax a CytochromeCapacity or any law returning μmol e⁻ m⁻² leaf s⁻¹, linear_atp_per_electron (η_L) and cyclic_atp_per_electron (η_C) a ConstantResponse or a temperature law; gamma_star may also be an AbstractCompensationPoint.

LeafPhotosynthesis.CytochromeRates Type
julia
CytochromeRates{FT}(; vcmax, vqmax, respiration, kc, ko, gamma_star,
    linear_atp_per_electron, cyclic_atp_per_electron)
CytochromeRates(vcmax, vqmax, respiration, kc, ko, gamma_star,
    linear_atp_per_electron, cyclic_atp_per_electron)

Store evaluated Cytochrome b₆f kinetic capacities and ATP coupling efficiencies at leaf temperature [K] and biochemical-site O₂ [Pa]:

  • vcmax, respiration: μmol CO₂ m⁻² leaf s⁻¹.

  • vqmax: μmol electrons m⁻² leaf s⁻¹.

  • kc, ko, gamma_star: Pa.

  • linear_atp_per_electron (η_L), cyclic_atp_per_electron (η_C): mol ATP (mol e⁻)⁻¹.

source
LeafPhotosynthesis.biochemical_rates Function
julia
biochemical_rates(responses, temperature[, oxygen]) -> C3Rates or CytochromeRates

Evaluate the kinetic rate parameters of responses (C3TemperatureResponse or CytochromeTemperatureResponse) at leaf temperature [K] and, when given, biochemical-site oxygen partial pressure [Pa], returning a C3Rates or a CytochromeRates.

The three-argument form passes oxygen to compensation_point for gamma_star; the two-argument form evaluates temperature-only laws, so it is a MethodError for an OxygenScaledCompensationPoint. A custom rate bundle needs only the two-argument method: the three-argument call falls back to it.

Photorespiratory Compensation Point ​

LeafPhotosynthesis.AbstractCompensationPoint Type
julia
AbstractCompensationPoint

Supertype for photorespiratory CO₂ compensation point (Γ* [Pa]) parameterizations.

source
LeafPhotosynthesis.PrescribedCompensationPoint Type
julia
PrescribedCompensationPoint(response)
PrescribedCompensationPoint(; response)

Wrap a temperature-only Γ* law response [Pa] calibrated at a fixed O₂ level.

The caller must supply an oxygen partial pressure compatible with response's calibration; this component does not infer oxygen scaling and is distinct from the signed or clipped carbon-assimilation policy.

source
LeafPhotosynthesis.OxygenScaledCompensationPoint Type
julia
OxygenScaledCompensationPoint(response, reference_oxygen)
OxygenScaledCompensationPoint(; response, reference_oxygen)

Scale a reference Γ* temperature law linearly with biochemical-site oxygen:   .

response evaluates Γ*(T, O_ref) [Pa] at the finite positive biochemical O₂ partial pressure reference_oxygen [Pa]. No ambient O₂ default or stoichiometric recalibration is introduced, and evaluation without an explicit oxygen argument is unsupported. The scalar law returns exact zero at oxygen == 0.

source
LeafPhotosynthesis.compensation_point Function
julia
compensation_point(response, temperature, oxygen)

Evaluate the photorespiratory CO₂ compensation point Γ* [Pa] at leaf temperature [K] and biochemical-site oxygen partial pressure [Pa].

Plain temperature laws delegate to temperature_response; implement a method on compensation_point when adding a new AbstractCompensationPoint.
