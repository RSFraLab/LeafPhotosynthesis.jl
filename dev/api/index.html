LeafPhotosynthesis.LeafPhotosynthesis Module
julia
LeafPhotosynthesis

Provide composable, zero-dependency scalar models for C3 leaf photosynthesis (Farquhar–von Caemmerer–Berry and Johnson & Berry 2021 Cytochrome b₆f + PSI/PSII coupling), analytical and equilibrium stomatal CO₂/H₂O gas exchange, oxygen budgets, LHCII state transitions (qT), and steady-state chlorophyll and PAM fluorescence across Float32, Float64, GPU kernels, and automatic differentiation.

source

The reference is grouped by biophysical process and covers every exported and every public name. Exported names are available after using LeafPhotosynthesis. Public names that are not exported (component helpers, evaluated rate bundles, status values and abstract types) are called as LeafPhotosynthesis.name or imported with using LeafPhotosynthesis: name.

Conventions ​

  • Units: leaf temperature in K; gas partial pressures and Michaelis–Menten constants (co2, oxygen, kc, ko, gamma_star) in Pa; photon, electron, carbon and oxygen area fluxes in μmol m⁻² leaf s⁻¹; molar conductances (g_sw, g_sc, g_bw, g_bc) and transpiration in mol m⁻² leaf s⁻¹.

  • No hidden constants: every physical, stoichiometric and reference parameter is passed explicitly by the caller (see examples/parameters/*.toml).

  • Types and devices: parameter and environment structs are parametric on the scalar type FT, allocate no heap memory per leaf evaluation, propagate ForwardDiff.Dual tangents and broadcast as scalars over CPU and CUDA arrays.
