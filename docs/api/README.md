# API Reference

[Repository README](https://github.com/RSFraLab/LeafPhotosynthesis.jl#readme) · [Worked Examples & Plots](../README.md) · [Interactive Gallery](../examples.html) · [Design Decisions](../design.md)

```julia
LeafPhotosynthesis
```

Provide composable, zero-dependency scalar models for C3 leaf photosynthesis
(Farquhar–von Caemmerer–Berry and Johnson & Berry 2021 Cytochrome b₆f + PSI/PSII
coupling), analytical and equilibrium stomatal CO₂/H₂O gas exchange, oxygen
budgets, LHCII state transitions (`qT`), and steady-state chlorophyll and PAM
fluorescence across `Float32`, `Float64`, GPU kernels, and automatic differentiation.

## Core Conventions

- **Units**: Leaf temperature in `K`; gas partial pressures and Michaelis–Menten constants (`co2`, `oxygen`, `kc`, `ko`, `gamma_star`) in `Pa`; photon, electron, carbon, and oxygen area fluxes in `μmol m⁻² leaf s⁻¹`; molar conductances (`g_sw`, `g_sc`, `g_bw`, `g_bc`) and transpiration in `mol m⁻² leaf s⁻¹`.
- **No hidden constants**: Every physical, stoichiometric, and reference parameter is passed explicitly by the caller (see `examples/parameters/*.toml`).
- **Type & device contract**: Parameter and environment structs are parametric on scalar type `FT`, allocate zero heap memory per leaf evaluation, propagate `ForwardDiff.Dual` tangents, and broadcast directly as scalars over CPU and CUDA arrays.
