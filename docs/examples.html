01 / THE FIRST CALL

Evaluate one leaf

Prescribe light, internal CO₂, and leaf temperature. photosynthesize returns carbon uptake and its component rates. Positive net assimilation means CO₂ uptake; negative values mean release.

julia --project=. examples/one_leaf.jl
Read the complete example

Configuration stays in read_parameters.jl; physical component assembly is visible in bonan_leaf.jl. The main script calls the biophysics.

02 / BONAN 11.1

Change one forcing at a time

These three curves use Bonan's C3 parameterization. In each panel, only the horizontal-axis variable changes. The Rubisco- and electron-limited curves have respiration subtracted, so they can be compared with net assimilation.

julia --project=. examples/bonan_11_1.jl
Read the complete response-curve example

The CO₂ axis is internal CO₂ mole fraction, not ambient CO₂. It represents the biochemical site here, with no mesophyll diffusion solve. Numerical curves pass an independent high-precision equation check; comparison with executed upstream MATLAB output remains pending. Scope and provenance →

03 / CONNECT THE COMPONENTS

Solve a leaf at equilibrium

Now prescribe ambient CO₂ and solve assimilation, diffusion, and Ball–Berry stomata together. CO₂ at the leaf surface, intercellular space, and biochemical site can differ. Temperature and humidity remain prescribed.

julia --project=. examples/core_exchange.jl
Read the complete equilibrium example

The derivatives describe the response to stomatal opening at fixed temperature. This is an illustrative component example, not a reproduction of Bonan 12.1. Equations and assumptions →

04 / LET STOMATA TAKE THEIR TIME

Turn the light on, then off

The prognostic model moves toward the current stomatal target. Its opening and closing time constants are separate parameters. Dashed lines show the fully coupled equilibrium for the same forcing, not the instantaneous target used in each prognostic step.

julia --project=. examples/stomatal_response.jl
Read the complete time-integration example

Temperature, surface humidity, and transport conductances stay fixed. The example uses an explicit Euler step; it does not provide a general-purpose integrator. Net O₂ release and net CO₂ uptake overlap for this example's core stoichiometry and respiratory quotient of one. This equality is not a universal physiological constraint. KEEP EXPLORING

Change a parameter. Rebuild the figures.

Edit the named values in bonan_11_1.toml or core_exchange.toml, then regenerate all plotted data:

julia --project=. docs/build_examples.jl

Reopen this file in a browser. Chart.js and all model results are bundled locally, so the gallery works offline. No server or JavaScript package installation is needed to view it.

Try changing opening_timescale while keeping closing_timescale fixed. Which part of the response changes? Then change the Ball–Berry slope and compare the new equilibrium.
